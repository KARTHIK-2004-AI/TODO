# SQLite Migrations Archive (Sprints 1 - 2.1)

These migrations are archived historical artifacts from when the application was powered by SQLite.
As of Sprint 3, the database provider has been permanently migrated to **MySQL**, and a new baseline migration `20260728000000_init_mysql_baseline` was generated for MySQL.

Archived SQLite migrations:
- `20260719162012_init` (Sprint 1 initial User and Todo models)
- `20260722204757_init` (Sprint 1 refinement)
- `20260723000000_add_user_profile_and_settings` (Sprint 2 profile and settings additions)
